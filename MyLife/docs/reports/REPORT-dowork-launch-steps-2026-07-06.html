7Phase 1: trainer's phone this week (EAS internal build)

About half a day of founder timeRun EAS commands from your own terminal, not a sandboxed Claude shell (eas-cli is broken there, see errors_log 2026-07-04; the GraphQL API is the fallback)
  1. Register the trainer's iPhone: from apps/dowork run eas device:create, text the registration link to your trainer, he opens it on his phone and installs the provisioning profile.
  2. Wire cloud env into preview builds: add one line to the preview profile in apps/dowork/eas.json: "environment": "production". The 5 EAS env vars (Supabase URL/key, cloud env, launch flag, auth redirect) already exist in the production environment; this reuses them. RC keys are not required (guard skips preview).
  3. Build: eas build --profile preview --platform ios from a checkout of the merged code. First run walks you through Apple login, registers the com.dowork.dowork bundle id, and mints the ad-hoc profile automatically.
  4. Install: send the trainer the EAS install link. He taps it on the registered iPhone and DoWork installs like a normal app.
  5. Keep Supabase awake: the free-tier project pauses after 7 idle days, which would look like a dead app mid-pilot. Upgrade to Pro (~$25/mo) or set a keep-warm ping before handing the build over.
  6. Onboard the trainer: send him the companion user guide. Order matters: email sign-in first, then redeem the fresh invite code, build the Studio, and upload 3+ videos.
  7. Run the white-glove QA checklist together (apps/dowork/Tickets/white-glove-qa-checklist.md, 9 sections): gym voice reality check, camera form checks, and the two-device coaching loop (use your phone as the client via eas device:create again or TestFlight later).
What works in this build
Everything except push and payments, live against production: trainer directory, Studio uploads, signed playback, voice player, client invites, form-check loop with timestamped feedback, offline downloads, account lifecycle, reporting/blocking. His invited clients get premium included, so nothing about the pilot needs money to move.
