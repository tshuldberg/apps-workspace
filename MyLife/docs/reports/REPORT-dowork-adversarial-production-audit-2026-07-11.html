Verdict: NO-GO for public launch — Overall 6/10

The substrate is genuinely well built: real RLS with no exploitable bypass, real full-cascade account deletion, real UGC moderation on every surface, honest server-truth monetization, and no fake-success stubs anywhere. The app is close.

It cannot ship today. Two paths on the flow every user hits after every workout silently lose data. The edge-function auth model rests on a deploy invariant nothing enforces. And the binary cannot be submitted without an app icon and an iOS privacy manifest. Fix the P0 and P1 sets and this is a GO.

P0 — Launch blockers

P0BH-2 — "Save Workout" button does nothing; public-share intent lost
save-workout.tsx:30-36 · verified in source

handleSave and handleDiscard are byte-for-byte identical — both just router.back(). The screen captures title, notes, and a Private/Everyone choice and throws it all away. The user titles a workout, picks "Everyone" to share, taps Save — nothing is titled or shared. (Raw session is persisted upstream, so history survives.)

Fix: persist title/notes to the session and call the existing uploadWorkoutShare when visibility is "Everyone", using a summary from buildWorkoutSummary + getSetWeightsForSession. Effort: M.

P0BH-1 — Ending a session mid-set silently discards the current set
session.tsx:510-529, 417-454 · verified in source

recordSetWeight runs only inside handleCompleteSet. handleEndWorkout → finalizeSession completes the session without flushing the current draft, so a typed-but-not-"Mark Complete" set is never written to wk_workout_set_weights — invisible to history and 1RM, no warning.

Fix: flush any draft with weight>0 && reps>0 before completing (or warn in the dialog). Effort: S.

P0BK-1 — No deploy-time enforcement that edge functions verify the JWT signature
_shared/broker.ts:147-159 · config.toml · missing dowork/scripts/deploy-functions.sh

getUserIdFromAuth decodes the JWT sub with no signature check; all 6 dowork-* functions trust the gateway's verify_jwt. None are pinned in config.toml, there is no deploy script, and no canary. One --no-verify-jwt slip at the manual F1 deploy → forge {"sub":"<victim>"} → account takeover via dowork-delete-account/dowork-playback-url.

Fix: pin verify_jwt = true for all 6 in config.toml; add a deploy script mirroring BestChef's; add a forged-JWT→401 smoke test; update the runbook. Effort: S.

P0LG-2 — No iOS Privacy Manifest (PrivacyInfo.xcprivacy)
not generated by hardening plugins; not on disk

Uses required-reason APIs (SecureStore/UserDefaults, SQLite file-timestamps) and bundles RevenueCat + Supabase. ASC's automated manifest check rejects after a successful build — an easy-to-miss submission-day failure.

Fix: add a manifest via config plugin (UserDefaults + file-timestamp reason codes, NSPrivacyTracking:false, collected-data types matching the policy). Effort: M.

P0 · founder-opsLG-1 — No app icon or splash image
app.json has only splash.backgroundColor; no assets/

Both stores reject binaries without a real icon. Tracked as founder-ops F8. Effort: M (art + wiring).

P0 · founder-opsLG-3 — ascAppId placeholder blocks submit
eas.json:26 = REPLACE_WITH_ASC_APP_ID

eas submit fails until the founder creates the $4.99 ASC record (founder-ops F2). Effort: S.

P1 — High (before public launch)

P1MN-1 — Cancellation revokes paid access immediately
dowork-rc-webhook/index.ts:37-43 + entitlement policy …:547-548 · verified

CANCELLATION → 'cancelled' fails the policy's status='active' clause, locking out a mid-period canceller from content they paid for. Fix: keep active on cancel; expire via current_period_end; flip only on EXPIRATION. S.

P1SH-1 — Five coaching-loop screens missing from Stack registration
(root)/_layout.tsx: my-trainer, clients, client-invite/[code], client-invite/index, form-check/[id]

Render outside parent screenOptions → white flash + native header on the product's core screens. Fix: add 5 <Stack.Screen> lines. S.

P1DL-1 — KV read-modify-write race loses download index (storage leak)
downloads.ts:102-114, pending-queues.ts:57-63

Two downloads finishing together clobber one index entry: file on disk, invisible, never deletable. Fix: wrap in transaction() or per-row keys. M.

P1CG-2 — Likes/comments/shares offline queues are in-memory only
cloud-likes.ts, cloud-comments.ts, cloud-shares.ts (self-flagged TODOs)

Offline social action + force-quit = silently lost; makes CLAUDE.md's KV-persistence claim overstated. Fix: extend pending-queues.ts KV persistence. M.

P1RT-6 — Transient mic error permanently locks out voice control
useVoiceCoach.ts:212-222

runtimeError is never cleared, pinning voice + push-to-talk to unavailable for the screen's life after any transient audio contention. Fix: clear on next start/foreground. S.

P1RT-7 — Push token removal wipes all of a user's devices
push.ts:277-289

Sign-out / notifications-off on one device deregisters push everywhere. Fix: scope token rows by device id. M.

P1RT-2 / RT-4 — Voice command races URL refresh; expiry only checked on foreground
player.tsx:426-475, 271-296

Seek reads stale duration during player.replace(); a long-foregrounded session isn't proactively refreshed past 60 min. Fix: isRefreshing gate + 60s expiry poll. M / S.

P1RT-8 — GPS elapsed timer not paused on background
gps.tsx:208-232

Route time drifts out of sync with point coverage (foreground-only permissions are correct). Fix: pause timer via AppState. S-M.

P1BH-3 — Plate calculator hides valid "bar only" result
calculator.tsx:45-49

Nulls the card when target ≤ bar though the library handles it. Fix: guard on ≤ 0. S.

P1DL-2 — Sign-out queue can leak across identities on persist failure
pending-queues.ts:104-114

Memory cleared then persisted; a persist throw leaves the prior user's queue on disk to rehydrate into the next user. Fix: catch/retry/surface. S.
