1State at a glance

MyNews is a signed-journalism platform: journalists publish under portable Ed25519 bylines, volunteer editors improve articles through author-controlled typed suggestions, and readers will support journalists directly with a disclosed 2% platform fee. The engineering core is real and deeply tested; the product is not yet launchable because operations, payments, account lifecycle, and several legal intake paths are incomplete. Remediation plan 48 is closing the code half; the founder runbook in section 7 is the operations half.

    console/ncii

    NCII / TAKE IT DOWN queue

    NCII reports are taken down immediately (take-down-first). The 48h clock is the window for human review, not for the content to stay up. Default is keep-removed; clearing a case lifts the takedown and needs explicit confirmation.

    1 open case · 0 past 48h SLA

    NCII queue — the automated worker can never clear a case; only a human with an explicit "confirm lift takedown" checkbox can. Console additions mid-build: full DMCA/counter-notice queue (WP2); MFA, RBAC, dual control, appeals (WP9).

    5User workflows (as wired today)

    Publish an article (journalist)

    Desk tab → New draft /compose?id=new. Pick News or Preprint; write; autosaves locally every 700ms.
    Tap Publish → Terms gate modal if this Terms version is unaccepted → device key signs the revision bytes.
    Edge function mynews-publish verifies the signature, suspension, and Terms fail-closed; server records but "cannot forge or alter your words."
    Local draft deletes; "Published and signed. Opening your article…" → article screen with signed revision history.

    Suggest and review an edit (editor + author)

    Any article → Suggest edit → pick type; corrections/context/translation demand an https citation; live diff preview.
    Submit (profile required) → signed with the editor key → lands in the author's Desk review queue; duplicates collapse into endorsements.
    Author opens the suggestion → Accept · publish rev N, Edit + accept (counter-edit), or Reject with an optional note; copyedits can batch into one revision with conflict detection.
    Acceptance publishes a new author-signed revision crediting the editor publicly; credibility points accrue with diversity/standing multipliers and 12-month decay.

    Read, follow, protect (reader)

    Discover → search or Latest → article. Follow from a journalist profile (device-local; shapes Today).
    Report anything (article, suggestion, profile) → reason + optional detail → atomic server intake; NCII reasons take content down immediately and start a 48h human-review clock.
    Block or Mute from a profile ("the account is never told"); manage in Me → Blocked accounts.
    If moderation ever acts on YOUR content, the DSA statement of reasons appears in Me → Notices.

    Account and first run

    First launch: local DB opens, device Ed25519 key generates silently; reading needs no account.
    Me → Create account (anonymous Supabase session) or magic-link email sign-in; then Register binds a public handle to the device key with proof-of-possession.
    Optional: "Start publishing" upgrades the profile to a journalist byline (bio, beats, region).
    First write action triggers the version-pinned Terms gate; server enforces the same version fail-closed.

    7Founder runbook: from this branch to App Store revenue

    Everything below is founder-operated (accounts, money, legal, vendors). All code paths already fail closed until each step is done, so these can proceed in order without waiting on the remaining code waves; step 12 is the only one gated on code completion. Exact env var names come straight from the source.

    Buy and wire the domain

    Registrar + DNS. Blocks: C01. Everything else references this origin.
    1. mynews.app is owned by a third party and for sale. Either negotiate its purchase or pick a controlled alternative (e.g. mynews.press, getmynews.com) — decide BEFORE store metadata, OAuth links, or legal copy are finalized.
    2. At the registrar: enable DNSSEC, add the apex + www records for the web host (step 5), and set up email: SPF, DKIM, DMARC records via your mail provider (Google Workspace or Fastmail is fine).
    3. Create monitored mailboxes: legal@, safety@, dmca@, support@. Route safety@ to a phone-alerting inbox; NCII has a 48h statutory clock.
    4. Send + receive a test email on each mailbox; keep the receipts.
    5. Tell the dev session the final domain: code updates apps/mynews-web/lib/origin.ts, the three contact addresses in modules/mynews/src/data/terms.ts, and store metadata in one sweep (bump Terms version together).

    Create the production Supabase project

    supabase.com dashboard + CLI. Blocks: C11.
    1. Create the project (choose region near your users). Record: project URL, anon key, service-role key.
    2. Auth settings: enable anonymous sign-ins and email (magic link); add redirect allowlist entries mynews://auth-callback (app) and https://<console-domain>/auth/callback (console).
    3. Enable extensions pg_cron and pg_net (Database → Extensions).
    4. Push migrations, scoped to MyNews: supabase db push from the repo applies supabase/migrations/; the nw_ set is 20260703000001..3, 20260705000001..10, and the new 20260712000001/3 (+2/6/7 when the waves land).
    5. Deploy the edge functions: mynews-publish, mynews-suggest, mynews-review, mynews-report, mynews-dmca, mynews-my-notices, mynews-register-key, mynews-set-meta, mynews-ncii-worker (+ mynews-payments-webhook, mynews-comment, mynews-account when landed). Never deploy any of them with --no-verify-jwt except mynews-ncii-worker, which is secret-gated by design.
    6. Post-deploy check: an unauthenticated POST to mynews-review must return 401. Keep the curl output as evidence.
    7. Set function secrets: MYNEWS_NCII_WORKER_SECRET (generate 32+ random bytes) and, later, the payments webhook secret.
    8. Insert the worker config rows in nw_job_config: functions_base_url = your functions URL, ncii_worker_secret = same secret. The pg_cron schedule (nw_run_ncii_worker, every 10 min) comes with the migrations.
    9. Plan tier: free projects pause after 7 idle days — use a paid tier for production. Turn on PITR backups.
