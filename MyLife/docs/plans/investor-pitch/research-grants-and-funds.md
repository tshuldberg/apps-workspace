### 1. NLnet Foundation -- NGI0 Commons Fund

**FIT SCORE: 9/10** -- Best grant opportunity on this list. Privacy-first, open-source-friendly, actively funding consumer apps.

| Field | Details |
|-------|---------|
| Amount | EUR 5,000 - 50,000 per project (can scale to EUR 500,000 over program lifetime) |
| Total pool | EUR 21.6M across all calls through 2027 |
| Current deadline | **June 1, 2026, 12:00 CEST** (13th call, opened April 1, 2026) |
| Decision timeline | ~3 months after deadline |
| Apply URL | [https://nlnet.nl/propose/](https://nlnet.nl/propose/) |
| Program page | [https://nlnet.nl/commonsfund/](https://nlnet.nl/commonsfund/) |
| Guide for applicants | [https://nlnet.nl/commonsfund/guideforapplicants/](https://nlnet.nl/commonsfund/guideforapplicants/) |

**Past software/tech recipients:**
- **WireGuard** -- VPN protocol, funded for privacy-enhancing networking
- **Mastodon** -- decentralized social network, funded for federation standards
- **CryptPad** -- encrypted collaborative office suite, funded for privacy features
- **Jitsi** -- open-source video conferencing, funded as secure Skype alternative
- **PeerTube** -- decentralized video hosting platform
- **Tor Hidden Services** -- anonymity infrastructure
- **NoScript** -- browser privacy/security extension
- **GNUnet** -- privacy-preserving networking framework
- **Nitrokey** -- open hardware security key (FIDO2 + encrypted storage)

57 projects were selected in the most recent (9th) call alone, with a high number of end-user-facing applications.

**Why these were accepted:** NLnet prioritizes projects that enhance privacy, give users control over their data, use open standards, and release under libre/open licenses. Consumer-facing tools that replace proprietary surveillance-based alternatives are explicitly favored.

**What makes a strong application:**
- Software must be released under a libre/open license (this is a hard requirement)
- Application of open standards where possible
- Clear privacy or trust-enhancing value proposition
- Concrete deliverables and milestones within the grant period
- Focus on user empowerment and data sovereignty
- Small, focused project scopes perform better than ambitious multi-year plans

**MyLife angle:** Position as privacy-first alternative to the Google/Apple lifestyle app ecosystem. Emphasize SQLite local-first architecture, zero analytics/telemetry, and open-source components. Could apply for a specific module (e.g., MyNotes as encrypted note-taking, or the privacy architecture itself). The open-source requirement means you would need to open-source at least the funded component.

**Gotchas:**
- Open source is mandatory -- cannot fund proprietary code
- EU-funded, but open to global applicants
- Previous NGI0 programs (PET, Entrust) are closed; Commons Fund is the active one

### 2. Open Technology Fund (OTF) -- Internet Freedom Fund

**FIT SCORE: 8/10** -- Large grants, rolling basis, strong privacy mandate. Funded Signal and Tor.

| Field | Details |
|-------|---------|
| Amount | $10,000 - $900,000 (target ceiling $300,000; most awards $50,000-$200,000) |
| Deadline | **Rolling basis** (no fixed deadline) |
| Decision timeline | Concept note review takes several weeks; full proposal by invitation; total ~3-6 months |
| Apply URL | [https://apply.opentech.fund/internet-freedom-fund-concept-note/](https://apply.opentech.fund/internet-freedom-fund-concept-note/) |
| Funds overview | [https://www.opentech.fund/funds/](https://www.opentech.fund/funds/) |
| Main site | [https://www.opentech.fund](https://www.opentech.fund) |

**Past software/tech recipients:**
- **Signal (Open Whisper Systems)** -- $3M+ since 2012 for encrypted messaging ([OTF project page](https://www.opentech.fund/results/supported-projects/open-whisper-systems/))
- **Tor Project** -- $3M+ for anonymity network ([OTF project page](https://www.opentech.fund/results/supported-projects/tor-project/))
- **Cryptocat** -- encrypted chat application (code audit funded)
- **GlobaLeaks** -- whistleblower platform
- **TextSecure** -- predecessor to Signal's encryption protocol
- **Ricochet** -- anonymous instant messaging over Tor

Over 2 billion people globally use OTF-funded software. Annual budget is $43.5M (FY2024). Over 3,500 funding requests reviewed since 2012.

**Why these were accepted:** OTF funds tools that counter censorship, resist surveillance, and promote internet freedom. Signal was funded because encrypted messaging directly enables free expression in repressive environments. Tor was funded for its censorship-circumvention capabilities.

**What makes a strong application:**
- Two-stage process: submit concept note first, then full proposal by invitation
- Must demonstrate clear internet freedom benefit (circumventing censorship, protecting privacy, enabling secure communication)
- Reviewed by OTF team AND independent Advisory Council of global experts
- Open to individuals and organizations (for-profit or nonprofit), any nationality
- Technology must be usable by at-risk populations (journalists, activists, citizens in repressive regimes)
- Open source strongly preferred

**MyLife angle:** Frame as "privacy-preserving alternative to surveillance-capitalism lifestyle apps." Emphasize zero-telemetry architecture, local-first data storage, and potential for use by journalists/activists who need personal organization tools that don't leak data to cloud providers.

**Gotchas:**
- OTF is a U.S. government-funded entity (via USAGM) -- this means potential political vulnerability (faced defunding attempts in 2020)
- Strong preference for tools with internet freedom applications, not just general privacy
- Most competitive of all grants on this list
- Also offers Core Infrastructure Fund and Rapid Response Fund for different scopes
