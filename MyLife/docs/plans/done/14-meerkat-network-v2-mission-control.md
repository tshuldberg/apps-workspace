- Owners: founder + per-zone agents (sync-dev, server-dev, rust-dev, ui-dev). Execution mode: one task at a time with founder review between milestones.

## Mission
Make Meerkat's encrypted device-to-device layer real (today: protocol-complete, transport-mocked), then grow it into friend-code trust, MLS group encryption, desktop-hosted encrypted communities with torrent-style seeding (channels/roles inside, D14), rentable zero-knowledge Hosted Nodes at transparent cost-plus pricing (D13), and a small first-party relay/rendezvous service tier. App-first; the overlay stays invisible until it has users.

## Non-goals (v2)
- No public content directory or discovery feed (invite links/codes only).
- No tokens/cryptocurrency, ever (D9).
- No phone seeding promises (D6).
- No VPN tier until subscriber gate (D12).
- No bespoke group crypto (MLS only, D3).

## Hard rules carried from v1 + audit
- Security lives in the payload; relays see ciphertext + ephemeral tokens only.
- `syncPolicy`/`maxScope`/`stripColumns` enforced OUTBOUND and (new) INBOUND.
- isSensitive modules require SAS-verified pairing before `shared_workspace`.
- Every milestone extends the red-team suite; no milestone ships with its gate tests red.
