# Behance — Deep Dive (vs MyCreate)

**Module:** create
**Tier:** adjacent (portfolio + community)
**Founded:** 2006
**HQ:** New York, USA
**Status:** acquired (Adobe, 2012)

## One-line
Adobe-owned portfolio network for designers, illustrators, motion artists; the default place to post finished creative work for hire.

## Product
- Project portfolios with images, video, case-study format
- Feed, follow graph, Appreciations (likes)
- Adobe Creative Cloud integration (one-click publish from Photoshop/Illustrator)
- Job board, ProSite / Behance Portfolio templates
- Platforms: Web (primary), iOS, Android
- Pricing: free (comes with Adobe account)
- Distinguishing UX choice: curated creative fields (illustration, photography, UX, motion) with admin-selected featured work

## Acquisition / Exit
- Acquired by: Adobe (NASDAQ: ADBE)
- Date: 2012-12
- Price: ~$150M estimated (cash; Adobe 8-K confirmed but exact split undisclosed)
- Current status inside parent: standalone brand, deeply integrated with Creative Cloud
- Strategic rationale: retention moat + designer-community defense against Pinterest/Dribbble
- Founder outcome: Scott Belsky ascended to Adobe CPO/EVP role (still there 2026); Matias Corea exited 2017

## Users
- 50M+ registered creatives (2024 company claim)
- MAU: ~15M est.
- Geography: global; US + EU + Latin America strong
- Creative-professional concentration (design, illustration, photography)

## How they make money (precise)
1. **Creative Cloud retention**: Behance is a free hook that keeps designers on Adobe subscriptions ($20-60/mo).
2. **Adobe Portfolio** ($9.99/mo add-on for custom-domain portfolios).
3. **Adobe Stock** cross-sell through Behance profiles.
4. No direct ads on main feeds.

Unit economics: N/A standalone; Behance is a margin-preserving moat around Creative Cloud.

## Wedge MyLife can exploit
- **Portfolio-only scope**: Behance is about publishing finished work, not tracking the making of it. MyCreate tracks projects, progress entries, photos, practice — the journey before publishing.
- **Public-by-default**: Behance requires public posts. MyCreate works privately until you're ready.
- **Adobe lock-in**: tight integration with Adobe tools; non-Adobe creators (writers, musicians, coders) are second-class. MyCreate is craft-agnostic.
- **No practice/skills tracking**: Behance measures posts + likes. MyCreate measures daily practice + skill progress.
