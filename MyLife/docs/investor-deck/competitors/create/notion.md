# Notion — Deep Dive (vs MyCreate)

**Module:** create
**Tier:** adjacent (creator templates)
**Founded:** 2013 (relaunched 2016)
**HQ:** San Francisco, USA
**Status:** private (VC-backed, late-stage)

## One-line
The all-in-one docs + database + wiki platform whose template ecosystem has become the default for creator project tracking.

## Product
- Pages, blocks, databases (tables, kanban, calendar, gallery)
- Wiki, project mgmt, docs, personal CRM
- AI (Notion AI Q&A, writing, autofill, Connectors to Google Drive / Slack / GitHub)
- Template marketplace (creator projects, portfolios)
- Platforms: iOS, Android, Web, macOS, Windows
- Pricing: Free (personal) / Plus $10/mo (individual); Business $18/mo; Enterprise custom
- Distinguishing UX choice: block-based infinitely nestable structure — users build their own tools

## How they make money (precise)
1. **Subscription seats** (Plus $10, Business $18, Enterprise custom).
2. **Notion AI** ($10/user/mo add-on).
3. **Template ecosystem** (no take-rate; drives organic growth, not revenue).

Unit economics: seat gross margin ~75-80%; enterprise contract TCV rising; AI add-on attaches ~15-20% of enterprise seats per reporting.

## Wedge MyLife can exploit
- **Notion is generic**: users cobble together project + portfolio templates. MyCreate ships a purpose-built creator tracker with progress entries, photo timelines, portfolio separation, equipment register out of the box.
- **Cloud-dependent**: Notion requires login + server storage. MyCreate runs local-first.
- **Enterprise focus**: Notion's roadmap increasingly favors work customers. Creators get templates, not product.
- **Per-user pricing**: $10/mo = $120/yr for one user; MyCreate is bundled in a $99/yr suite.
