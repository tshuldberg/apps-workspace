# Wanderlog — Deep Dive (vs MyTravel)

**Module:** travel
**Tier:** direct
**Founded:** 2018
**HQ:** San Francisco, California, USA
**Status:** private (Y Combinator W19)

## One-line
A collaborative trip-planning app that turns a blank map into a shared itinerary with your travel group — freemium with a $49.99/yr Pro tier, growing on Gen Z group-trip planning.

## Product
- Collaborative itineraries (multi-user, real-time)
- Places to visit saved directly from a built-in map
- Booking confirmation import (email forwarding like TripIt)
- Budget tracker per trip
- Route optimizer (reorder stops for shortest drive)
- Offline access (Pro)
- Platforms: iOS, Android, Web
- Pricing: Free / Pro $49.99/yr (trial 7 days), family plan $79.99/yr
- Distinguishing UX choice: real-time collaboration on a trip map — Google Docs for travel

## How they make money (precise)
1. **Pro subscription** ($49.99/yr): unlimited trips, offline maps, collaborators, route optimizer.
2. **Family plan** ($79.99/yr): 6 members.
3. **Affiliate bookings**: Booking.com, GetYourGuide integrations pay referral commissions.

Unit economics: small eng team + cloud collab infra; est. 65-75% gross margin on Pro.

## Wedge MyLife can exploit
- **Cloud-dependent collaboration**: Wanderlog's collab requires server-side sync + account. MyTravel is local-first by default; collab can be opt-in via MyLife Presence module.
- **No bucket list / memory layer**: Wanderlog is planning-only, deletes trips after return. MyTravel's `tv_memories` + bucket-list turns trips into lifetime log.
- **Single-app stack**: user still needs AllTrails for hike, Surfline for surf, Day One for journal. MyLife delivers travel + trails + surf + journal in one suite.
- **Privacy**: Wanderlog stores locations, routes, group chats on servers. MyTravel keeps destinations and journal on device.
