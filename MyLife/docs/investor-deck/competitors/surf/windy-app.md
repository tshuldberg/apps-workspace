# Windy.app — Deep Dive (vs MySurf)

**Module:** surf
**Tier:** direct
**Founded:** 2014
**HQ:** Prague, Czech Republic (with Limassol, Cyprus operating entity)
**Status:** private

## One-line
A wind-and-waves forecast app for surfers, sailors, kiters, and fishermen, known for clean multi-model overlays (GFS, ECMWF, ICON) and a one-price-fits-all premium tier. Not to be confused with Windy.com (separate company).

## Product
- Multi-model forecasts (NOAA GFS, ECMWF, ICON, AROME, HRRR)
- Wave height, period, swell direction, wind speed + gusts
- 40+ weather layers on map (radar, storms, isobars)
- Spot feed with ratings/comments
- Community photo uploads per spot
- Platforms: iOS, Android, Web
- Pricing: Free (limited) / Premium ~$34.99/yr (sometimes $49.99/yr regionally)
- Distinguishing UX choice: power-user model comparison — users can flip between weather models to decide which to trust

## How they make money (precise)
1. **Premium subscription** (~$34.99/yr): unlocks all weather models, extended forecast, premium overlays.
2. **Lifetime/one-time upgrades**: occasional offers for PRO pack.
3. No ads. No data licensing disclosed.

Unit economics: lean engineering team (<30 est.), pure cloud forecast ingestion, >75% est. gross margin on subs.

## Wedge MyLife can exploit
- **Fragmented positioning**: Windy.app covers many sports (sail, kite, fish, surf); MySurf is surfer-native with surfer-native rating (Go/Maybe/No) and wave physics.
- **No session logging**: Windy.app tracks forecasts, not surfed sessions. MySurf logs sessions with GPS wave detection.
- **Cross-module**: a Windy.app user still needs a separate hike app, budget app, journal app. MyLife bundles surf + 29 other modules for $99/yr.
- **Naming collision**: consumer confusion with Windy.com hurts brand equity. MySurf has clean mono-product identity.
