- Disease/pest diagnosis via photo
- Care calendar, watering reminders, plant library, light meter
- Expert botanist Q&A (premium)
- Platforms: iOS, Android, Web (lead-gen only)
- Pricing: 7-day free trial → $29.99/yr Premium (or aggressive $2.99/wk = $155/yr annualized)
- Distinguishing UX: sub-second identification accuracy on phone-camera photos

## How they make money (precise)
1. **Annual subscription** $29.99/yr — the default post-trial charge.
2. **Weekly subscription** $2.99/wk — annualized $155, captures impulsive trial converters.
3. **Paid user acquisition** on Facebook/TikTok/Apple Search Ads with heavy LTV modeling — the competitive moat is acquisition, not product.

Unit economics: ~$15-25 CAC, ~$45-60 LTV; very tight economics requiring constant creative testing. Subscription retention ~30-40% year 2 (typical plant-ID vertical).

## Wedge MyLife can exploit
- **Identification-only product:** PictureThis identifies plants; it does not plan layouts, compute companion planting, track harvest yields, model frost dates, or manage propagation cuttings. MyGarden does all six.
- **Aggressive paywall / dark patterns:** consumer trust issues documented via App Store review sentiment — $2.99/wk "trial" traps.
- **No cross-module context:** PictureThis cannot link a tomato harvest to a MyRecipes dish or a MyDining companion meal.
- **Cloud-only ID:** every photo uploaded to Glority servers. MyGarden's identification engine runs with local caching and a user-owned plant library.
- **Suite bundle price advantage:** $29.99/yr PictureThis vs ~$84-120/yr MyLife suite including 30 modules — the unit value is 30x.
