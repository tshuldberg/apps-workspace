# PlantIn — Deep Dive (vs MyGarden)

**Module:** garden
**Tier:** direct
**Founded:** 2020
**HQ:** Cyprus (Vortemol Limited; operated by Ukrainian dev team)
**Status:** private (bootstrapped / lightly funded)

## One-line
A PictureThis clone that competes on price + care-planner depth, part of the wider Vortemol portfolio of utility-subscription apps built by Eastern European dev studios.

## Product
- Plant identification via photo
- Disease/pest diagnosis
- Personalized care schedules, watering reminders, light tips
- Plant encyclopedia with expert articles
- Botanist chat (premium)
- Platforms: iOS, Android, Web (marketing)
- Pricing: 3-day or 7-day free trial → $24.99/yr or $4.99/wk Premium
- Distinguishing UX: care-first framing (planner + reminders) vs PictureThis's identification-first framing

## How they make money (precise)
1. **Annual subscription** $24.99/yr — the "value" anchor after trial.
2. **Weekly subscription** $4.99/wk — impulse capture for users who skip the annual option.
3. **Paid user acquisition** heavy on Meta + TikTok; LTV / CAC management is the core competency.

Unit economics: $15-20 CAC (emerging markets cheaper), $35-50 LTV. Churn in year 2 is the pressure point.

## Wedge MyLife can exploit
- **Opaque ownership:** Cypriot shell company with no identifiable founders. MyLife is a US-based transparent entity with a privacy-first brand.
- **No depth features:** PlantIn does ID + care reminders; no companion planting, layout planner, frost dates, harvest analytics, propagation tracking. MyGarden has all of these.
- **Cloud-dependent:** all plant identification requires server upload. MyGarden caches locally and can work offline post-initial ID.
- **Copycat roadmap:** PlantIn tails PictureThis features rather than pioneer; MyGarden's layout planner + light classification + companion matrix are not replicable without rebuilding the stack.
- **Suite bundle:** $24.99/yr standalone vs MyLife suite at ~$84-120/yr for 30 modules.
