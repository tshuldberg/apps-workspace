# Power Planner — Deep Dive (vs MyClasses)

**Module:** classes
**Tier:** direct
**Founded:** 2014
**HQ:** Seattle, WA, USA
**Status:** private (solo indie, BareBones Dev LLC)

## One-line
A Windows/Xbox-Store heritage student planner rewritten cross-platform; known for grade-projection ("What If?") mode and GPA math.

## Product
- Class schedule (semesters, terms)
- Assignment and exam tracker
- Grade calculator with weighted categories and GPA
- "What if?" mode for grade scenarios
- Automatic reminders
- Platforms: iOS, Android, Windows, Mac, Web
- Pricing: free / Premium $4.99 one-time (unlocks >5 grades per class, multi-semester, theme pack)
- Distinguishing UX choice: one-time purchase model (extremely rare in student apps) and "What If?" grade calculator

## How they make money (precise)
1. **Premium IAP** ($4.99 one-time, unlocks across all platforms tied to Microsoft account).
2. No subscription. No ads on paid tier. Minimal ads on free tier historically.

Unit economics: tiny LTV but near-zero support cost; sustainable for solo dev but unlikely to scale to modern SaaS CAC.

## Wedge MyLife can exploit
- **Solo-dev velocity cap**: Power Planner ships slowly. MyClasses ships with a full team cadence via MyLife hub.
- **No degree-requirement tracking, no application pipeline, no lifelong learning**: Power Planner stops at "what did I get on this test?" MyClasses goes further.
- **No Pomodoro or time tracker**: Power Planner doesn't measure study time. MyClasses has both.
- **Weak mobile Polish**: UI feels UWP-first. MyClasses is mobile-native on iOS and Android.
