# MyTherapy — Deep Dive (vs MyMeds)

**Module:** meds
**Tier:** direct (Europe-led free med tracker, pharma-subsidized)
**Founded:** 2012
**HQ:** Munich, Germany
**Status:** private (smartpatient GmbH; 80+ employees)

## One-line
The most-used medication app in the world (12M+ users) — free to consumers because pharma pays for the digital patient-support platform underneath.

## Product
- Pill + injection + measurement reminders
- Symptom diary, mood tracking, activity tracking
- Family accounts + carer notifications
- Pharma-sponsored condition programs (MS, IBD, Parkinson's, transplant)
- eRx (e-prescription) integration in Germany
- Pricing: free (100%); no premium tier for consumers
- Platforms: iOS, Android, Web

## How they make money (precise)
1. **Pharma platform licensing**: MyTherapy's "OS for pharma digital patient services" — white-labeled condition programs for pharma.
2. **Integration fees**: eRx (Germany), provider/pharmacy integrations.
3. **Clinical outcomes data licensing**: aggregated adherence/symptom datasets.
4. **Consumer**: $0 revenue directly (free app, always has been).

## Wedge MyLife can exploit
- **100% pharma-funded.** MyTherapy's product roadmap is steered by pharma partners. MyMeds has no such dependency; feature priority is user-driven.
- **Shallow vitals.** MyTherapy tracks reminders well but does not ship BP classification, glucose TIR, insulin IOB, CGM AGP, pain heatmap, FODMAP correlation — MyMeds ships all six.
- **No doctor-grade report.** MyTherapy exports CSV; MyMeds emits markdown doctor/therapy report with wellness score.
- **Server-dependent.** MyTherapy is a cloud platform; MyMeds is SQLite on device.
- **Free is a feature until it isn't.** MyTherapy is free because pharma pays — which means data privacy is structurally misaligned. MyMeds is part of a $99/yr suite with zero data licensing.
