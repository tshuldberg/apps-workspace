# Day One — Deep Dive (vs MyJournal)

**Module:** journal
**Tier:** direct (premium personal journal, category benchmark)
**Founded:** 2011
**HQ:** Salt Lake City, UT (now Automattic subsidiary)
**Status:** private (Automattic subsidiary since 2021)

## One-line
The Apple Design Award-winning gold standard for personal journaling — encrypted cloud sync, on-this-day nostalgia, and a $35/yr premium that built a 200k+ subscriber base.

## Product
- Multiple journals with tags, location, weather, photos, audio, video
- On-this-day, streaks, templates, Apple Watch complication
- End-to-end encrypted cloud sync (Day One's hallmark)
- AI-generated prompts + insights (added 2024)
- Book publishing service (physical print-on-demand)
- Pricing: free (1 journal); Premium $34.99/yr
- Platforms: iOS, iPadOS, macOS, Android, Web

## How they make money (precise)
1. **Day One Premium** ($34.99/yr): primary revenue. Unlocks unlimited journals, audio/video, end-to-end encrypted sync.
2. **Day One Book**: physical print-on-demand of journals. Paid per book (~$30-80 per).
3. **Automattic cross-sell**: WordPress.com / Tumblr ecosystem tie-ins (early stage).

## Wedge MyLife can exploit
- **Paywalled features include core CBT, affirmations, vision boards.** Day One has journaling but no CBT thought records, no 15 cognitive distortions, no therapy prep templates, no affirmations engine, no philosophy quotes. MyJournal ships these in the free tier.
- **Cloud-only premium.** Day One's differentiator is E2E sync; MyJournal is SQLite on device (trade-off: no cross-device by default).
- **No cross-module correlation.** Day One entries don't know the user's mood, habits, meds. MyJournal participates in the hub's Pearson engine.
- **Pricing.** $34.99/yr Day One alone vs $99/yr MyLife suite covering 31 modules (journal + mood + habits + meds + ...).
- **Web surface gap is closeable.** Note: MyJournal mobile has 21 routes vs web's 5 — this is MyLife's own largest surface gap and should be addressed before investor pitch.
