# Flo Health — Deep Dive (vs MyCycle)

**Module:** cycle
**Tier:** direct
**Founded:** 2015
**HQ:** London, UK (Cyprus-registered parent)
**Status:** private (unicorn, VC-backed)

## One-line
The world's largest period + fertility + pregnancy tracker; first femtech unicorn; cloud-based by design with a history of regulatory and privacy controversies.

## Product
- Cycle log (period, symptoms, mood, sex, notes)
- Fertility window + ovulation predictions
- Pregnancy mode + week-by-week
- Health assistant + chatbot + editorial articles
- Anonymous Mode (2022, post-Dobbs response)
- Platforms: iOS, Android, Web
- Pricing: free / Premium $9.99/mo or $49.99/yr (renamed "Flo Premium"; lifetime deal occasionally)
- Distinguishing UX choice: editorial content + AI chatbot wrap every tracking action

## How they make money (precise)
1. **Premium subscription** ($9.99/mo or $49.99/yr): AI chatbot, advanced cycle analysis, secret chats.
2. **Health-provider B2B** (minor): data-licensing-free research partnerships.
3. Ads (minor; mostly turned off post-privacy settlements).

Unit economics: ARPU ~$20 blended; CAC ~$5 (word-of-mouth + app-store SEO moat); very high gross margin.

## Wedge MyLife can exploit
- **Data sold / shared controversy**: Flo settled with FTC in 2021 for sharing data with Facebook/Google. Brand trust eroded. MyCycle stores data on-device with zero server backend.
- **Dobbs-era liability**: US users subpoena risk. Flo's Anonymous Mode is a feature flag; MyCycle has no server to subpoena.
- **Partner sync via account**: Flo's partner-view requires a Flo account for the partner. MyCycle uses device-to-device share codes with granular per-field privacy.
- **Monetization pressure**: Flo's premium is $50/yr for one app; MyLife suite at $99/yr covers cycle + budget + mood + 25 others.
