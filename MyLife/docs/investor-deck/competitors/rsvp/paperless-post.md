# Paperless Post — Deep Dive (vs MyRSVP)

**Module:** rsvp
**Tier:** direct
**Founded:** 2009
**HQ:** New York, NY
**Status:** private (VC-backed, mature)

## One-line
Premium digital invitations with print-quality designs and designer collaborations, targeting weddings, showers, and mid-market milestone events where aesthetics and etiquette matter.

## Product
- Flyer (free digital invites) + Paperless Post cards (coin-based premium designs)
- Custom printing option (physical cards delivered)
- RSVP tracking, guest messaging, event pages, registry links
- Designer collabs (Kate Spade, Rifle Paper Co., Oscar de la Renta)
- **Platforms:** iOS, Android, Web (web-first)
- **Pricing:** Free digital (Flyer); "Coins" purchased in bundles ($5-100+) for premium invites; custom print upsell
- **Distinguishing UX:** luxury-tier design aesthetic, print-parity, wedding stationery market cred

## How they make money (precise)
Primary: Coins — users buy packs ($5 for ~5 coins up to $100 for ~200), spend ~3-15 coins per premium invite. Average premium event = ~$30-80 in coins. Secondary: physical printing markup (Kate Spade set printed = ~$200+ per event). Tertiary: Plus subscription ~$100/yr for frequent hosts. Unit economics favor wedding/bar-mitzvah scale events ($200-500 per host) over birthdays.

## Wedge MyLife can exploit
- **Coin system is a dark pattern:** fixed pricing feels more honest; users resent leftover coins. MyLife charges flat subscription, unlimited events.
- **Premium-only design moat is weakening:** Canva/AI can now generate comparable designs. MyLife can ship template generator.
- **Narrow use case:** Paperless Post wins weddings but loses casual/recurring events. MyLife handles both.
- **No life integration:** Paperless Post is invitation-only. MyLife connects to Budget (cost tracking per event), Friends (guest history), Recipes (menu planning).
