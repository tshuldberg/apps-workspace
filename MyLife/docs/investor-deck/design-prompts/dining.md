# MyDining Investor Mockup Prompts

**Module one-liner:** Remember every meal.
**Accent color:** #DC2626 (deep red)
**Marquee features to showcase:** Restaurant diary with visits and dishes and wines, map of your actual eating history, year-in-review and wishlist with reservations.
**Wedge vs competitors:** A personal food diary that is yours, not Yelp's crowd-sourced profile.

## Prompt 1 - Hero screen (mobile 390x844)

```
Design MyDining home, 390x844, iOS, #131318. Top: "Recent visits" header. Body: vertical list of visit cards, each with hero photo of the dish, restaurant name, date, companion avatars, dish count chip. Accent red #DC2626 on highlight. Bottom tab: Diary, Wishlist, Map, Wines. Editorial restaurant-review mood, quiet not foodie-loud.
```

## Prompt 2 - Secondary screen (mobile 390x844)

```
Design a restaurant detail, 390x844, #131318. Hero photo top third. Below: restaurant name, cuisine tag, 5-visit counter. Carousel of dishes eaten, each with price and rating. Notes field. Wine pairings row. Bottom pill "Log a visit" red #DC2626. Warm, memoir-like, no Yelp star overload.
```

## Prompt 3 - Web dashboard (1440x900)

```
MyDining web, 1440x900. Sidebar 72px with dining tile red. Main canvas: dark map with visit pins across a city, left rail showing a diary scroll of past meals. Right rail 360px: year-in-review stats, top cuisines, wine log. Background #131318. Cartographer-calm, not Google Maps-busy.
```

## Prompt 4 - Marketing still (1920x1080)

```
1920x1080 investor still. iPhone on a dark restaurant table with a blurred wine glass and candle. MyDining visit card on screen, red #DC2626 accent. Headline "Remember every meal." Inter 56pt #E4E1E9, sub "Your diary, not Yelp's profile." #D6C3B5. Background #0E0E13. Candlelit, intimate, not flashy.
```

## Prompt 5 - Animation brief (6-second vertical loop)

```
6s vertical 1080x1920. Beat 1, 0 to 1.5s: dish photo zooms in softly. Beat 2, 1.5 to 3s: visit card slides up with companion avatars. Beat 3, 3 to 4.5s: map pans and a new red pin drops. Beat 4, 4.5 to 6s: wine glass chip appears, year-counter ticks to 147 meals, reset. Warm, cinematic.
```
