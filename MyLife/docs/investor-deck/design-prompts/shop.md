# MyShop Investor Mockup Prompts

**Module one-liner:** Your private shopping memory.
**Accent color:** #10B981 (emerald)
**Marquee features to showcase:** Universal wishlists across sites, purchase journal with receipt capture, warranty and return deadline tracker.
**Wedge vs competitors:** One private record of what you've bought, what you wanted, and what's still under warranty, no Amazon profile lock-in.

## Prompt 1 - Hero screen (mobile 390x844)

```
Design MyShop home, 390x844, iOS, #131318. Top: "Wishlist" section card, 3 items with photos and priority chips. Below: "Purchases" recent list with receipt thumbnail, merchant, amount, warranty-expiry chip emerald #10B981 when active. Bottom tab: Wishlist, Purchases, Warranties, Gifts. Quiet shopping-record mood.
```
