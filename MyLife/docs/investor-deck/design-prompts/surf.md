# MySurf Investor Mockup Prompts

**Module one-liner:** Surf forecasts and spot intel, no ads, no tracking.
**Accent color:** #3B82F6 (blue)
**Marquee features to showcase:** 41+ seeded spots with NOAA hourly forecast and swell and tides, Go / Maybe / No verdict at a glance, session logging with GPS wave detection.
**Wedge vs competitors:** Surfline-grade data without the paywalled forecast and ad-filled app.

## Prompt 1 - Hero screen (mobile 390x844)

```
Design MySurf home, 390x844, iOS, #131318. Top: region picker chip (California). Body: spot list, each with name, wave-height range, verdict chip "Go" blue #3B82F6 / "Maybe" amber / "No" muted, wind glyph. AI narrative preview card. Bottom tab: Spots, Forecast, Sessions, Alerts. Coastal-calm, not neon.
```
