# MyTrails Investor Mockup Prompts

**Module one-liner:** Offline hiking and trail guide.
**Accent color:** #65A30D (olive green)
**Marquee features to showcase:** GPS recording with elevation and pace, offline map regions with tile downloads, segments with KOM-style efforts and packing templates.
**Wedge vs competitors:** AllTrails-grade trail data without the paywall on offline maps, plus trip itineraries.

