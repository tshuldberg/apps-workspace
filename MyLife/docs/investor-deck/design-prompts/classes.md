# MyClasses Investor Mockup Prompts

**Module one-liner:** Own your academic life.
**Accent color:** #3B82F6 (blue)
**Marquee features to showcase:** Class schedule plus assignments and grades, degree progress with requirement satisfaction, study sessions with Pomodoro and time tracking.
**Wedge vs competitors:** A real gradebook plus degree tracker plus study timer in one private app, no Chegg paywall or MyStudyLife ad banner.

## Prompt 1 - Hero screen (mobile 390x844)

```
Design MyClasses home, 390x844, iOS, #131318. Top: week strip Mon to Sun, today highlighted blue #3B82F6. Body: stacked class cards in time order, each with course code, room, professor, and assignment count badge. Glass surfaces, 16px radius. A "Today's focus" card pins the next due assignment. Bottom tab: Schedule, Assignments, Grades, Study. Scholarly, calm, no neon.
```
