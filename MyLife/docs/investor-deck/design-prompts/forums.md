# MyForums Investor Mockup Prompts

**Module one-liner:** Human-verified community, bot-free by design.
**Accent color:** #7C4DFF (electric violet)
**Marquee features to showcase:** Threaded discussions with voting and communities, binary human verification via passkey/biometric, transparent public mod log.
**Wedge vs competitors:** Reddit-style discussion with bots actually removed and moderation visible to everyone.

## Prompt 1 - Hero screen (mobile 390x844)

```
Design MyForums home feed, 390x844, iOS, #131318. Top: filter strip All, Humans Only, Joined. Body: stacked post cards, each with community tag, title, preview, vote arrows violet #7C4DFF, comment count. "Verified human" chip on a few posts. Bottom tab: Feed, Communities, Messages, Mod Log. Reddit-familiar yet calm, no clickbait thumbnails.
```

## Prompt 2 - Secondary screen (mobile 390x844)

```
Design a community detail with mod log, 390x844, #131318. Top: community header with member count and Humans Only badge violet. Tabs: Posts, Mod Log, Rules. Mod Log visible: list of actions with timestamp and reason, public by default. Subscribe pill bottom. Transparent, civic, not dark-mode Discord.
```
