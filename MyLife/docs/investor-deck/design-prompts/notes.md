# MyNotes Investor Mockup Prompts

**Module one-liner:** Private knowledge engine with markdown, wiki linking, and intelligence.
**Accent color:** #64748B (slate)
**Marquee features to showcase:** Markdown with wiki backlinks and FTS5 search, infinite canvas with nodes and edges, Notion-style relational databases.
**Wedge vs competitors:** Obsidian-grade linking plus Notion-grade databases plus whiteboard, all private, free tier.
