# MyFriends Investor Mockup Prompts

**Module one-liner:** Remember who matters to you.
**Accent color:** #EC4899 (pink)
**Marquee features to showcase:** People + circles with hangouts log, frequency and social-energy engines that nudge drifting friendships, gifts and life-event reminders.
**Wedge vs competitors:** A relationship CRM that stays private, no growth-hack SaaS harvesting your contacts.

## Prompt 1 - Hero screen (mobile 390x844)

```
Design MyFriends home, 390x844, iOS, #131318. Top: "People" title. Body: 2-column grid of friend cards, each with avatar circle, name, circle tag (Inner, Close, Orbit), last hangout date, and a pink #EC4899 "drifting" dot when the frequency engine flags them. Bottom tab: People, Circles, Hangouts, Memories. Warm, personal, not contacts-app cold.
```

## Prompt 2 - Secondary screen (mobile 390x844)

```
Design a person detail, 390x844, #131318. Top: large avatar, name, circle badge. Timeline of hangouts vertical scroll. Cards for gifts given, upcoming birthday, life events. Bottom pill "Plan a hangout" pink #EC4899. Affectionate, memoir-adjacent.
```

## Prompt 3 - Web dashboard (1440x900)

```
MyFriends web, 1440x900. Sidebar 72px friends tile pink. Main: 3-column grid of people cards with social-energy ring badges. Right rail 360px: this-week birthdays, hangouts planned, drift warnings. Background #131318. Gentle, journaling-app vibe.
```

## Prompt 4 - Marketing still (1920x1080)

```
1920x1080 investor still. iPhone on a dark surface with a blurred coffee cup. People grid visible with pink #EC4899 drift indicator. Headline "Remember who matters." Inter 56pt #E4E1E9, sub "A relationship CRM that stays yours." #D6C3B5. Background #0E0E13. Warm, not saccharine.
```

## Prompt 5 - Animation brief (6-second vertical loop)

```
6s vertical 1080x1920. Beat 1, 0 to 1.5s: avatar circles fade in a grid. Beat 2, 1.5 to 3s: a "drifting" dot pulses pink on one card. Beat 3, 3 to 4.5s: hangout timeline slides in, a new entry is added. Beat 4, 4.5 to 6s: gift idea chip floats, reset. Gentle, social.
```
