# MyLife Hub Dashboard Investor Mockup Prompts

**Module one-liner:** Your entire life, one suite, privacy-first.
**Accent color:** #FFB877 (hub primary) with per-module accents in the module grid
**Marquee features to showcase:** Today rail pulling highlights across every enabled module, module grid tiles with accent colors and quick glances, suite-wide search and quick-log.
**Wedge vs competitors:** The only hub bundling 30+ modules under one private subscription, no analytics, no telemetry.
