# MyMail Investor Mockup Prompts

**Module one-liner:** Self-hosted private email.
**Accent color:** #3B82F6 (blue)
**Marquee features to showcase:** Multi-account IMAP with local metadata, threaded conversations with FTS search and drafts, filters and attachments with encryption keys.
**Wedge vs competitors:** IMAP client that never pipes mail through a third-party relay, with on-device search and filtering.

## Prompt 1 - Hero screen (mobile 390x844)

```
Design MyMail inbox, 390x844, iOS, #131318. Top: account picker chip blue #3B82F6. Body: message list with sender, subject, preview, star, unread dot. Search bar at top. Compose FAB blue bottom right. Bottom tab: Inbox, Starred, Drafts, Search. Crisp mail-client polish, not Superhuman neon.
```

## Prompt 2 - Secondary screen (mobile 390x844)

```
Design a threaded conversation, 390x844, #131318. Top: subject line and participant avatars. Stacked messages, latest expanded, older collapsed. Reply bar bottom with attachment icon. Encryption key icon in header blue when keys attached. Email-craft clean.
```

## Prompt 3 - Web dashboard (1440x900)

```
MyMail web, 1440x900. Sidebar 72px mail tile blue. 3-pane: folders 260px, thread list 380px, reader pane flex. Right rail 300px: filter rules editor with condition chips. Background #131318. Trusted mail-client feel, Outlook-minus-bloat.
```

```
6s vertical 1080x1920. Beat 1, 0 to 1.5s: inbox list scrolls into place. Beat 2, 1.5 to 3s: new message slides in top with a blue unread dot. Beat 3, 3 to 4.5s: thread expands, messages stack. Beat 4, 4.5 to 6s: filter rule applies, message files itself to a folder, reset.
```
