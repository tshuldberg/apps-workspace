**Accent color:** #C9894D (warm gold) with phase-tint accents
**Marquee features to showcase:** Cycle calendar with phase tracking and weighted predictions, BBT temperature charting with coverline, pregnancy mode with 4 due-date methods.
**Wedge vs competitors:** Post-Dobbs private tracking, on-device, no server account, no subpoena surface.
