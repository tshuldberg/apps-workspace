# MyBooks Investor Mockup Prompts

**Module one-liner:** Read in peace.
**Accent color:** #C9894D (warm amber)
**Marquee features to showcase:** Shelves with reading sessions and FTS search, built-in ePub/PDF reader with annotations, connected book clubs with pace tracking.
**Wedge vs competitors:** The only reader app combining Goodreads-style tracking, a native reader, and bot-free clubs inside a private suite.

## Prompt 1 - Hero screen (mobile 390x844)

```
Design a mobile library home for MyBooks, 390x844, iOS. Obsidian Noir background #131318 with subtle warm glow. Top: title "Library" in SF Pro 28pt #E4E1E9. Grid of 6 book covers with glass tiles, 16px radius. Row above showing "Currently Reading" with thin amber #C9894D progress bar at 42 percent. Bottom tab bar with Library, Discover, Reader, Insights icons. No em dashes. Calm, literary, bookstore-at-night mood.
```
