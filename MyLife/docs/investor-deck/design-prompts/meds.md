# MyMeds Investor Mockup Prompts

**Module one-liner:** Your private health command center.
**Accent color:** #06B6D4 (cyan)
**Marquee features to showcase:** Medication tracking with reminders and refills and supply alerts, drug interaction checker with 200+ pair database, BP/glucose/A1c logging with classification.
**Wedge vs competitors:** MyTherapy plus GoodRx plus health-logger in one private app with a doctor-report export.

## Prompt 1 - Hero screen (mobile 390x844)

```
Design MyMeds today home, 390x844, iOS, #131318. Top: "Today's doses" header. Body: vertical dose cards with med name, dosage, scheduled time, cyan #06B6D4 take-pill circle. Low-supply warning badge on one card. Bottom tab: Today, Meds, Vitals, Report. Clinical, neat, respectful.
```

## Prompt 2 - Secondary screen (mobile 390x844)

```
Design a drug interaction checker, 390x844, #131318. Top: two med chips, "Lisinopril" and "Ibuprofen". Body: severity card "Moderate, monitor BP" cyan border, explanation paragraph, 3 suggested actions. Respectful, pharmacy-grade.
```
