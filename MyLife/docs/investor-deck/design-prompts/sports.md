# MySports Investor Mockup Prompts

**Module one-liner:** Your sports life, together.
**Accent color:** #16A34A (green)
**Marquee features to showcase:** Live scores across NFL/NBA/MLB/NHL/MLS with followed-team dashboard, adaptive polling, bet tracking and fantasy companion.
**Wedge vs competitors:** theScore-grade scoreboard without gambling dark patterns or sponsored content.

## Prompt 1 - Hero screen (mobile 390x844)

```
Design MySports home, 390x844, iOS, #131318. Top: followed team row with tier chips (Casual, Fan, Diehard) green #16A34A. Body: live games list with score tiles, inning/quarter badges, rival flags. Bottom tab: Scores, Teams, Bets, Fantasy. Sports-bar-at-home mood, no ads.
```

## Prompt 2 - Secondary screen (mobile 390x844)

```
Design a game detail, 390x844, #131318. Top: team logos (monochrome placeholders if needed) and live score. Tabs: Box Score, Play-by-play, Stats, Bets. Active Play-by-play list with inning/time chips. Green #16A34A active state. Calm scoreboard polish.
```
