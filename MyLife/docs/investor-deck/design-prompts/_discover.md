# MyLife Discover Investor Mockup Prompts

**Module one-liner:** Browse every module, enable what you need.
**Accent color:** #FFB877 (hub primary)
**Marquee features to showcase:** Full 30+ module catalog with tier chips (free/premium), one-tap enable that runs migrations and activates routes, search and category filters.
**Wedge vs competitors:** A marketplace of modules inside one app, no App Store purchase per tool.

## Prompt 1 - Hero screen (mobile 390x844)

```
Design the MyLife Discover screen, 390x844, iOS, #131318. Top: search bar and filter row (All, Free, Premium, Health, Money, Creative, Life). Body: module tile grid 2 columns, each tile with emoji, name, tagline, tier chip (Free tinted green, Premium tinted primary #FFB877). Bottom tab: Home, Discover, Search, Settings. Clean marketplace, not App Store loud.
```

## Prompt 2 - Secondary screen (mobile 390x844)

```
Design a module detail sheet, 390x844, #131318. Modal sheet: hero icon in module accent, name, one-liner promise, tier badge. Body: 3 feature bullets, screenshot strip, storage type chip. Bottom: enable pill in primary #FFB877. Respectful sell, not growth-hack.
```

## Prompt 3 - Web dashboard (1440x900)

```
Design the MyLife web Discover, 1440x900. Sidebar 72px. Main: filter chip row top, 4-column module catalog grid, each tile animating hover lift. Right rail 360px: module detail pane with feature list and enable button. Background #131318. Editorial-gallery feel, not e-commerce.
```

```
1920x1080 investor still. iPhone with Discover grid visible, module accent colors glowing softly. Headline "One app. Thirty lives." Inter 64pt #E4E1E9, sub "Enable only what you use." #D6C3B5. Primary #FFB877 underline. Background #0E0E13. Calm confidence.
```

## Prompt 5 - Animation brief (6-second vertical loop)

```
6s vertical 1080x1920. Beat 1, 0 to 1.5s: tiles tile in from bottom, staggered. Beat 2, 1.5 to 3s: user taps a tile (MyGarden), detail sheet slides up. Beat 3, 3 to 4.5s: enable pill tap, primary ring fills, migrations spin, checkmark. Beat 4, 4.5 to 6s: new tile appears in hub grid lime lit, reset.
```
