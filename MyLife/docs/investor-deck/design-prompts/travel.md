# MyTravel Investor Mockup Prompts

**Module one-liner:** Plan trips, collect memories.
**Accent color:** #0EA5E9 (sky blue)
**Marquee features to showcase:** Trips with logistics and budget, visited and bucket-list destinations with trip map, travel journal with photos.
**Wedge vs competitors:** TripIt-meets-Polarsteps without the social feed, private by default.

## Prompt 1 - Hero screen (mobile 390x844)

```
Design MyTravel home, 390x844, iOS, #131318. Top: upcoming trip hero card with destination photo placeholder, dates countdown chip sky #0EA5E9. Body: trip list with dates, budget status. Bottom tab: Trips, Destinations, Journal, Map. Travel-diary calm.
```

## Prompt 2 - Secondary screen (mobile 390x844)

```
Design a trip detail, 390x844, #131318. Top: cover photo, dates, budget progress bar sky #0EA5E9. Tabs: Itinerary, Budget, Journal, Packing. Active itinerary list with day headers and event chips. Thoughtful traveler.
```

MyTravel web, 1440x900. Sidebar 72px travel tile sky. Main: world map with visited/bucket pins left, trip detail right. Right rail 360px: budget summary, journal preview. Background #131318. Cartographic-nautical.
