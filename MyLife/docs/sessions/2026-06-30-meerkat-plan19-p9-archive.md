- **C1 (HIGH, pre-existing): omitted cm_ tables silently replicated at shared_workspace.** `ChangeTracker` resolves a cm_ table to the community module and falls back to `policy.defaultScope`, which was `shared_workspace` — so a cm_ table OMITTED from `entityRules` LEAKED (contradicting the "device_local by omission" comments). Updated 2 pre-existing tests that had encoded the leak as "local by omission".
- **C2 (MEDIUM, pre-existing): directory takedown reversible by public replay.** `recordUnpublish` deleted the durable record with NO tombstone, so a third party could re-announce the original active genesis and re-list it in browse/trending for a TTL (the community-node was already immune via my A2 monotonicity). Fix: `removeContentIfUnreferenced` scans the publication store and only un-pins when no OTHER active publication references that contentId (added a `list()` to PublicationStore + both impls).
