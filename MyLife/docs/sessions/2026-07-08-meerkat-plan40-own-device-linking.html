Started Plan 40 Section 1 by adding the visible same-account "link this second device" flow on mobile and web. The implementation reuses the existing pairing, SAS, mailbox, dm_own_devices, linkOwnDeviceCore, and provider-level linkOwnDevice paths.

Built

  • Shared pure own-device status helpers for mobile and web.
  • Real status reads from dm_own_devices, dm_messages, and dm_delivery.
  • Candidate gating for active, SAS-verified, unrevoked paired devices.
  • Mobile OwnDeviceLinkCard in Messages and Settings.
  • Web OwnDeviceLinkPanel in Messages and Settings.
  • Mailbox-check actions that report only real foreground-drain results.
  • Mobile foreground-drain receipt counts so signed receipt arrivals refresh the status.
  • Meerkat parity locks for the new surfaces and shared helper parity.

Honesty Boundaries

Implemented: with no linked own device, the UI says direct messages are local to this device. Linking records an existing paired device in dm_own_devices only. Convergence is not claimed after linking alone.

Proof gate: convergence copy appears only after real mirrored DM rows and signed receipts from linked own devices are stored locally.
