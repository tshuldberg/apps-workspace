## Key Patterns Learned
- Optional native imports can emit a red error before catch; inspect the registered bridge before loading WebRTC.
- An authenticated friend is not an own-device replica; check the recipient before serializing private rows.
- A listener returning normally is not sync success: propagate its recorded session and require completed status; calculate backoff after the attempt.
- Whole-image browser databases need lifetime writer ownership before loading, legacy-version fencing, and vault-first durable saves; a write-only lock cannot repair stale snapshots.

- A TypeScript adapter that imports an absent native package is a capability shell, not a completed native transport.
- Production readiness requires executable recovery and failure evidence, not only a passing happy-path test suite.
- With many sessions open, run checks sequentially and use FUNCTION_GATE_MAX_WORKERS=1 to reduce memory.
- Parallel fix waves on the same surface produce semantic duplicate fixes (two session-meta writers, two cancellation models); merge by choosing one write model and verifying against the DB policy and tests, not by textual conflict-picking.
