AppToolbar.tsx

2 · Open animation & geometry

PinwheelMenu.tsx

Tapping the anchor measures its on-screen position with measureInWindow, opens a transparent Modal, and runs a single Animated.Value from 0 → 1 with useNativeDriver: true. Each icon's translate is interpolated from the shared progress, so all six animate in lockstep without per-icon overhead.

Sequence

1 · Tap anchor → measureInWindow(...) resolves the screen-space center → state & modal open → Animated.spring(progress → 1) fans icons out.

2 · Tap an icon → selection haptic → Animated.timing(progress → 0) collapses the wheel → on completion, router.push(action.route).

3 · Tap backdrop or center × → light impact haptic → animate close, no navigation.

page-sheet modal

6 · Persistence schema

rc_settings table

Configuration lives in the existing rc_settings table — same key/value store the rest of the app already uses for zip code, theme mode, and chef defaults. Three keys plus one per page-override.

KeyTypeDefaultPurpose
pinwheel_default_actionsJSON string[]DEFAULT_PINWHEEL_ACTIONSGlobal ordered list, max 6
pinwheel_show_labels"true" | "false""true"Captions under each fan-out icon
pinwheel_enabled"true" | "false""true"Master switch
pinwheel_page_<key>JSON string[]—Optional override for a specific page (home, kitchen, profile, …)

Reading config

import { usePinwheelConfig } from '../data/pinwheel-config';

const db = useDatabase();
const config = usePinwheelConfig(db, 'home');
// config.actions    → ordered PinwheelActionDef[] (resolved from override → default)
// config.showLabels → boolean
// config.enabled    → boolean

7 · Wiring into a screen

AppToolbar.tsx

The toolbar handles the anchor for you. Pass pinwheelPageKey to enable per-page overrides, or omit it to fall back to the global default. Pass hidePinwheel to opt out entirely on a screen (e.g. the submit modal where the action would be redundant).

import { AppToolbar } from '../components/AppToolbar';

return (
  <View style={[styles.screen, { backgroundColor: tc.background }]}>
    <View style={{ paddingTop: insets.top }}>
      <AppToolbar
        pinwheelPageKey="home"
        onSearch={() => router.push('/discover')}
        onSubmit={() => router.push('/submit')}
        onNotifications={() => router.push('/notifications')}
      />
    </View>
    {/* page body */}
  </View>
);

9 · QA checklist

pre-merge
  • Anchor renders in header on Home, Leaderboard, Profile.
  • Tap → fan-out with spring; backdrop dims to 0.55.
  • Tap action closes wheel and routes to target route.
  • Tap backdrop / center × closes without routing.
  • Settings → Default editor saves picks; preview strip updates instantly.
  • Per-page override applies only on that page; reset arrow restores default.
  • Show labels toggle hides/shows captions globally.
  • Master switch off hides the anchor; bell/search/+ remain visible.
  • Haptics fire on open / select / close.
  • App restart persists default and overrides via rc_settings.
